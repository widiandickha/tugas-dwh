# Dokumen Kamus Data (Data Dictionary) Data Warehouse

Dokumen ini disusun oleh **Anggota 1 (Data Architect & Business Analyst)** sebagai acuan spesifikasi teknis basis data bagi **Anggota 2 (Data Cleansing)** dan **Anggota 3 (ETL & Database)** untuk memastikan konsistensi penamaan kolom, tipe data, serta aturan transformasi.

Target Database: **MySQL 8.x (InnoDB, utf8mb4)**

---

## 1. Tabel Dimensi: `dim_date`
* **Peran**: Menyimpan informasi kalender dan periode waktu pemesanan untuk agregasi analitik tren (harian, bulanan, kuartal, tahunan).
* **Granularitas**: 1 baris merepresentasikan 1 tanggal unik dalam rentang transaksi.

| Nama Kolom | Tipe Data MySQL | Kategori Kunci / Peran | Nullable | Nilai Default | Sumber Dataset Kaggle | Keterangan & Logika Bisnis |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| `date_key` | `INT` | Primary Key (SK) | NO | - | Generated | Format angka integer `YYYYMMDD` (contoh: 20180115). |
| `full_date` | `DATE` | Atribut | NO | - | `olist_orders_dataset.order_purchase_timestamp` | Nilai tanggal standar `YYYY-MM-DD`. |
| `day` | `INT` | Atribut | NO | - | Generated | Nilai hari dalam bulan (1 s.d. 31). |
| `month` | `INT` | Atribut | NO | - | Generated | Nilai angka bulan (1 s.d. 12). |
| `month_name` | `VARCHAR(20)` | Atribut | NO | - | Generated | Nama bulan dalam bahasa Inggris (January, February, dst). |
| `quarter` | `INT` | Atribut | NO | - | Generated | Angka kuartal kalender (1 s.d. 4). |
| `year` | `INT` | Atribut | NO | - | Generated | Angka tahun empat digit (2016, 2017, 2018). |
| `day_of_week` | `VARCHAR(20)` | Atribut | NO | - | Generated | Nama hari (Monday, Tuesday, dst). |
| `is_weekend` | `TINYINT(1)` | Atribut | NO | `0` | Generated | Flag penanda akhir pekan: `1` untuk Sabtu/Minggu, `0` untuk hari kerja. |

## 2. Tabel Dimensi: `dim_customers`
* **Peran**: Menyimpan profil pelanggan dan geografi domisili pemesan.
* **Granularitas**: 1 baris merepresentasikan 1 customer ID transaksi.

| Nama Kolom | Tipe Data MySQL | Kategori Kunci / Peran | Nullable | Nilai Default | Sumber Dataset Kaggle | Keterangan & Logika Bisnis |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| `customer_key` | `INT AUTO_INCREMENT` | Primary Key (SK) | NO | Auto | Generated by DWH | Surrogate key integer unik buatan DWH. |
| `customer_id` | `VARCHAR(50)` | Natural Key (NK) | NO | - | `olist_customers_dataset.customer_id` | Hash identitas pemesan per transaksi. |
| `customer_unique_id` | `VARCHAR(50)` | Atribut Bisnis | NO | - | `olist_customers_dataset.customer_unique_id` | Hash identitas unik individu pelanggan (digunakan untuk analisis retensi / repeat buyer). |
| `customer_city` | `VARCHAR(100)` | Atribut | YES | NULL | `olist_customers_dataset.customer_city` | Nama kota domisili pelanggan (dibersihkan huruf kapitalnya oleh Anggota 2). |
| `customer_state` | `VARCHAR(10)` | Atribut | YES | NULL | `olist_customers_dataset.customer_state` | Kode dua huruf negara bagian di Brazil (SP, RJ, MG, dst). |
| `customer_zip_code_prefix` | `VARCHAR(10)` | Atribut | YES | NULL | `olist_customers_dataset.customer_zip_code_prefix` | Kode pos 5 digit wilayah domisili pelanggan. |

## 8. Tabel Fakta: `fact_order_items`
* **Peran**: Tabel fakta pusat yang merekam transaksi penjualan pada tingkat unit item produk dan durasi logistik.
* **Granularitas**: 1 baris per 1 item produk dalam 1 transaksi pesanan (`order_id` + `order_item_id`).

| Nama Kolom | Tipe Data MySQL | Kategori Kunci / Peran | Nullable | Nilai Default | Sumber Kolom Asli | Keterangan & Logika Bisnis |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| `fact_id` | `BIGINT AUTO_INCREMENT` | Primary Key (SK) | NO | Auto | Generated by DWH | Surrogate key utama tabel fakta. |
| `customer_key` | `INT` | Foreign Key | NO | - | `dim_customers.customer_key` | Relasi ke dimensi pelanggan. |
| `product_key` | `INT` | Foreign Key | NO | - | `dim_products.product_key` | Relasi ke dimensi produk. |
| `seller_key` | `INT` | Foreign Key | NO | - | `dim_sellers.seller_key` | Relasi ke dimensi penjual. |
| `order_date_key` | `INT` | Foreign Key | NO | - | `dim_date.date_key` | Relasi ke dimensi tanggal pembelian. |
| `order_status_key` | `INT` | Foreign Key | NO | - | `dim_order_status.status_key` | Relasi ke dimensi status pesanan. |
| `payment_key` | `INT` | Foreign Key | NO | - | `dim_payments.payment_key` | Relasi ke dimensi pembayaran. |
| `review_key` | `INT` | Foreign Key | YES | NULL | `dim_reviews.review_key` | Relasi ke dimensi ulasan (NULL jika belum ada ulasan). |
| `order_id` | `VARCHAR(50)` | Degenerate Dimension | NO | - | `olist_order_items_dataset.order_id` | Nomor transaksi pemesanan asli. |
| `order_item_id` | `INT` | Degenerate Dimension | NO | - | `olist_order_items_dataset.order_item_id` | Urutan item di dalam satu transaksi (1, 2, 3, dst). |
| `price` | `DECIMAL(12,2)` | Numeric Measure | NO | 0.00 | `olist_order_items_dataset.price` | Nilai harga barang satuan (BRL). |
| `freight_value` | `DECIMAL(12,2)` | Numeric Measure | NO | 0.00 | `olist_order_items_dataset.freight_value` | Biaya ongkos kirim per item (BRL). |
| `total_item_value` | `DECIMAL(12,2)` | Numeric Measure | NO | 0.00 | Dihitung: `price + freight_value` | Total nilai kotor item transaksi. |
| `shipping_duration_days` | `DECIMAL(6,2)` | Numeric Measure | YES | NULL | Dihitung: `delivered_customer_date - purchase_timestamp` | Durasi hari yang dibutuhkan hingga barang sampai ke pembeli. |
| `delivery_delay_days` | `DECIMAL(6,2)` | Numeric Measure | YES | NULL | Dihitung: `delivered_customer_date - estimated_delivery_date` | Selisih hari keterlambatan pengiriman terhadap estimasi (nilai positif = terlambat, negatif = lebih cepat). |
| `is_delayed` | `TINYINT(1)` | Flag Indicator | NO | 0 | Dihitung: `delivery_delay_days > 0` | Flag biner: `1` jika pesanan terlambat, `0` jika tepat waktu / lebih awal. |
